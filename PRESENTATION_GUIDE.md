# Presentation Guide

## Introduction

Good day. I am Samuel C. Sales Jr., also known as Thirdy. This is my Basic Web E-Portfolio.

## Portfolio Design

I kept my original Thirdy Portfolio concept: the dark-red background, red accent color, fixed navigation, profile images, About Me, Motivation, Hobbies, Contact, Address, cards, and hover effects.

## Web System and Architecture

The website uses HTML, CSS, and JavaScript. HTML provides the content and structure, CSS handles the visual design and responsive layout, and JavaScript handles the music player.

The browser is the client side. There is no required database or backend because this is a static portfolio. VS Code is used for editing and Live Server can run the files locally. GitHub Pages can host the site online.

## Interactive Interface

I will demonstrate:

- Home, About, Contact, and Address navigation;
- social-media buttons;
- the Start button;
- the Play Game button;
- Contact and Maps links; and
- the music player.

## Multimedia

The two multimedia types are **images and audio**.

The music player has three local MP3 slots and supports play/pause, previous/next, progress seeking, volume, playlist selection, automatic next track, and Spotify links.

The audio player uses `preload="metadata"` so the browser does not need to download an entire song before playback is requested.

## Testing

I tested navigation, links, images, the music player controls, responsive layout, and all three local audio files. Written test results and a checklist are included in the `evidence` folder.

## Evaluation

Two things that work well are the consistent original design and the functional music player.

Two weaknesses in the previous version were the large visible Exam Requirements section and the old Gaming card.

Two improvements were removing the visible Exam section while keeping the evidence files, and replacing Gaming with the optimized Spotify-inspired audio player.
